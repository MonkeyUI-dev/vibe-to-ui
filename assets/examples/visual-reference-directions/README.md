# Visual-reference starter set

These preview-only examples let a new user try an image-led `vibe-to-ui` workflow without first supplying their own reference material.

| File | Direction | What it demonstrates |
| --- | --- | --- |
| `editorial-cobalt-glass.png` | Editorial architecture | Precise spatial rhythm, strong contrast, and blue glass against stone. |
| `tactile-amber-membrane.png` | Tactile material | Experimental product material, controlled glow, and generous negative space. |
| `material-paper-glass.png` | Quiet natural material | Calm composition, paper texture, and restrained organic color. |

Use these only as high-level visual input. Generate fresh assets that fit the user's product and selected direction; do not copy a reference literally or add generated assets to a project before the user chooses a direction.
